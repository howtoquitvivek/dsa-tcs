Good beginner recursion problems progression:

# Very Basic

1. Print 1 to N
2. Print N to 1
3. Sum of first N numbers
4. Factorial
5. Fibonacci
6. Power of number
7. Count digits
8. Sum of digits

---

# Beginner Recursive Arrays

9. Print array
10. Find maximum in array
11. Find minimum in array
12. Sum of array
13. Reverse array
14. Check sorted array
15. Linear search recursively

---

# Beginner Recursive Strings

16. Reverse string
17. Palindrome string
18. Remove character recursively
19. Count vowels recursively
20. Check anagram recursively

---

# Important Logic Building

21. Binary search recursion
22. GCD recursion
23. Decimal to binary recursion
24. Generate binary strings
25. Tower of Hanoi

---

# Real Recursion Start

26. Subsequences
27. Subsets
28. Combinations
29. Permutations

---

# Backtracking Beginner

30. Rat in maze
31. N queens
32. Sudoku solver
33. Word search

---

# Most Important Transition

| Stage                    | Main Learning       |
| ------------------------ | ------------------- |
| basic recursion          | stack flow          |
| recursive arrays/strings | parameter movement  |
| subsets/permutations     | recursion tree      |
| backtracking             | choose-explore-undo |
